05 · Responsive rules

What changes below 640px

  1. Header. One 56px bar: logo, avatar, menu button. The tab row moves into a side drawer with language toggle, email and sign out - no more half-cut tabs.
  2. Page header. Title and description stack full width. Action buttons sit in a 2-column row under them (grid 1fr 1fr), 44px tall, text on one line.
  3. Tables become cards. History rows turn into cards: week + teacher on top, status tag at the end, details as label/value pairs, row action as a full-width link at the bottom.
  4. Car cards wrap into 3 rows: car + transmission, teachers + Assign, then Edit/Delete as 44px icon buttons.
  5. Week grid keeps all 6 days on screen: short day letters, cells 48px tall with no "Open" text (the legend says it). Only "חסום" is labelled. No sideways scrolling.
  6. Publish moves to a sticky bottom bar, full width.
  7. Floor. Body text at least 13px, tap targets at least 44px, nothing nowrap except buttons and tags.

09 · Rules for 06 to 08

New decisions

  1. ⋮ on a card. 44px button in the top row's end corner, right after the status tag. The menu opens below it, anchored to that corner, 44px items. A "fix" item goes first, tinted sky, above a divider.
  2. Muted items (Inactive, Deleted): card loses its shadow and goes near-white; avatar, name and details fade to 55%. The status tag and the action (⋮ or Restore) stay full strength so they still read and tap.
  3. Action that replaces ⋮ (Restore) sits at the bottom of the card as a full-width 44px text row, like History's row link.
  4. Flags (deleted teacher, not this teacher's car) sit inline after the value they describe: Plum icon + 13px text, wrapping onto a new line when needed.
  5. LTR values (ID, phone, email, link) are isolated dir="ltr" spans. Long emails and links wrap with overflow-wrap:anywhere instead of truncating.
  6. Filters stack full width: teacher select, then the 3-way status control (equal thirds), then search. They stay visible in the no-match state.
  7. One header action goes full width. Hide it when an empty state already shows the same button.
  8. Three header actions. The text action (Extend deadline) moves up next to the deadline it changes; the other two take the 2-column row.
  9. Stat chips sit in 3 equal columns, labels wrap to two lines. The "data as of" stamp goes on its own line under them.
  10. Count grid uses 12×10px card padding, a 46px label column and 4px gaps: cells are about 39px wide at 360px. Cells show the number only; the legend explains.
  11. Slot detail. Count cells with 1+ requests are tappable (stronger border; selected cell gets a sky outline). Tap opens a bottom sheet: day, window and count on top, then each student's name with which pick this slot was for them. 0 and blocked cells do nothing.
  12. Phone-only labels. "ייבוא רשימת תלמידים" → "ייבוא רשימה" with the upload icon. Every other label stays as it is.
